Introduction

1. The Concept of "Mapping"

ORM (Object-Relational Mapping) acts as a mirror. It translates your Python data structures into SQL tables seamlessly.

Python Class

Represents an entire SQL Table.

Attribute

Represents a Column (e.g., name, email).

Instance

Represents a Row (a specific record).

Technical

2. Implementation Guide

Step A: The Engine (The Connection)

from sqlalchemy import create_engine

# SQLite (Local File)
engine = create_engine('sqlite:///my_database.db')

# PostgreSQL (Server)
# engine = create_engine('postgresql://user:pass@localhost/mydb')

Step B: The Model (The Structure)

from sqlalchemy import Column, Integer, String
from sqlalchemy.orm import declarative_base

Base = declarative_base()

class User(Base):
    __tablename__ = 'users'
    id = Column(Integer, primary_key=True)
    name = Column(String)
    email = Column(String, unique=True)

# Physical creation of tables in the database
Base.metadata.create_all(engine)

3. Pure SQL vs SQLAlchemy

Action Pure SQL (Text) SQLAlchemy (Object)
Insert INSERT INTO users... session.add(User(name="Marc"))
Select All SELECT * FROM users session.query(User).all()
Filter ... WHERE id=1 session.query(User).get(1)
Search ... WHERE name LIKE '%Ma%' filter(User.name.contains('Ma'))
