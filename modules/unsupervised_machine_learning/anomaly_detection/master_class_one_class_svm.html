1. The Core Idea: Learning a Boundary Around Normality

The One-Class Support Vector Machine (SVM) is an unsupervised algorithm that learns a decision boundary around a set of "normal" data points. Instead of separating two classes, it separates the data from the origin, effectively creating a contour that encloses the majority of the data. Any point falling outside this boundary is considered an anomaly.

2. How It Works

The One-Class SVM operates by:

  • Mapping to a Higher Dimension: Using a kernel function, the data is mapped to a high-dimensional feature space.
  • Finding the Optimal Hyperplane: The algorithm finds a hyperplane that separates the data points from the origin with the maximum margin.
  • Defining the "Normal" Region: The region on the side of the hyperplane containing the data is considered "normal." The other side is the "anomalous" region.
  • The $\nu$ Parameter: A key parameter, $\nu$ (nu), acts as an upper bound on the fraction of training points that can be outliers and a lower bound on the fraction of support vectors.

3. Strengths and Weaknesses

Strengths

  • Effective in High-Dimensional Spaces: Works well with a large number of features.
  • Robust to Overfitting: The use of a margin maximizes the separation, making the model more general.
  • Handles Non-Linear Boundaries: With the use of kernel functions, it can learn complex, non-linear shapes of normality.

Weaknesses

  • Sensitive to Parameters: The choice of the kernel and the $\nu$ parameter can significantly impact performance.
  • Can be Computationally Intensive: Training time can be long, especially on large datasets.

4. Conclusion

The One-Class SVM is a powerful tool for anomaly detection, especially in scenarios where you have a good understanding of what "normal" looks like and want to identify anything that deviates from it. It's widely used in areas like industrial monitoring and intrusion detection.
