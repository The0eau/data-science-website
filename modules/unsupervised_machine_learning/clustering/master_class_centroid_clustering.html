1. The Core Idea: Partitioning Data into K Groups

Centroid-based clustering algorithms are fundamental unsupervised methods that partition a dataset into a pre-determined number (K) of distinct, non-overlapping clusters. The goal is to create groups where the points within a cluster are as similar as possible, and the points in different clusters are as dissimilar as possible.

2. Two Key Algorithms

K-Means

K-Means is the most famous and widely used clustering algorithm. It works by iteratively assigning each data point to the nearest cluster centroid (the mean of the points in that cluster) and then recalculating the centroid. This process minimizes the within-cluster sum of squares (variance). It is fast and scales well to large datasets.

K-Medoids

K-Medoids is a robust alternative to K-Means. Instead of using a calculated mean as the cluster center, it uses an actual data point from the cluster, known as the medoid. This makes it much less sensitive to outliers. The algorithm iteratively swaps medoids with non-medoid points to find the configuration that minimizes the total distance between points and their assigned medoid.

3. Strengths and Weaknesses

Strengths

  • Simple and Fast: Both algorithms are easy to understand and computationally efficient.
  • Scalable: K-Means, in particular, scales well to very large datasets.
  • K-Medoids is Robust to Outliers: Provides a significant advantage in noisy datasets.

Weaknesses

  • Need to Specify K: The number of clusters, K, must be chosen beforehand.
  • Assumes Spherical Clusters: Both algorithms work best when clusters are roughly spherical and of similar size.
  • Sensitive to Initialization: The initial choice of centroids/medoids can affect the final clustering result.

4. Conclusion

K-Means and K-Medoids are essential tools for data exploration and customer segmentation. K-Means offers speed and simplicity, making it a great starting point. K-Medoids provides robustness, making it a better choice when dealing with datasets containing significant outliers or noise.
