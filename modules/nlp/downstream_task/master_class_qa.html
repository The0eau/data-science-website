1. The Core Idea: Reading Comprehension for Machines

Question Answering (Q&A) is the task of automatically answering questions posed by humans in a natural language. A Q&A model is given a question and a context (a piece of text containing the answer), and it must identify the span of text in the context that answers the question. This is also known as "extractive question answering".

2. How it Works: Fine-tuning Transformers for Q&A

Like many other NLP tasks, Q&A models are typically built by fine-tuning a pre-trained transformer model (like BERT or DistilBERT) on a question-answering dataset. The model learns to predict the start and end positions of the answer span within the given context. The output is the piece of text that lies between these two positions.

3. The Difference with Semantic Search

While both can be used to answer questions, there is a key difference:

  • Semantic Search: Retrieves a list of relevant documents that are likely to contain the answer.
  • Question Answering: Takes a single document and extracts the specific answer from it.

The two are often used together in a pipeline: first, semantic search is used to find the most relevant documents, and then a Q&A model is used to extract the precise answer from those documents.

4. Conclusion

Question answering is a powerful tool for information retrieval and a key component of many conversational AI systems. It allows users to get direct answers to their questions without having to read through long documents. As models become more powerful, they are able to answer increasingly complex questions and to reason over multiple pieces of information.
