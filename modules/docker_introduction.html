Docker Training Summary: Running Containers

This document summarizes the basic steps to execute and interact with Docker containers.

1. Running a Container

To run your first container, use the Docker Command Line Interface (CLI).

$ docker container run -t ubuntu top
  • docker container run: Command to start a new container.
  • -t: Allocates a pseudo-TTY for interactive commands.
  • ubuntu: The base image.
  • top: The process running inside the isolated PID namespace.

2. Working with Docker Hub

Docker Hub is the central registry for official and community images.

Deploying NGINX

$ docker container run --detach --publish 8080:80 --name nginx nginx

3. Building Custom Images

The Dockerfile defines the environment for your application.

# Example Dockerfile
FROM python:3.6.1-alpine
RUN pip install flask
COPY app.py /app.py
CMD ["python", "app.py"]

Building and Pushing

$ docker image build -t username/my-app .
$ docker push username/my-app

4. Docker Swarm Orchestration

Swarm manages a cluster of nodes, ensuring high availability and scaling.

$ docker swarm init --advertise-addr eth0
$ docker service create --name web-service --replicas 3 -p 80:80 nginx
Pro Tip: Always use an odd number of Managers (3, 5, or 7) to maintain Quorum and prevent "split-brain" scenarios.
