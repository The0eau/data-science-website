1. The Core Idea: Representing Classes by Their Center

The Centroid Partition Classifier (or Nearest Centroid Classifier) is a very simple and efficient algorithm. It represents each class by a single point: its centroid, which is simply the average of all the training samples belonging to that class.

2. The Classification Process

To classify a new data point, the algorithm performs a straightforward calculation:

  • Find Centroids: In the "training" phase, the model calculates the central point (mean vector) for each class.
  • Calculate Distances: For a new point, it calculates the distance from that point to the centroid of each class.
  • Assign Class: The new point is assigned to the class of the closest centroid. This effectively carves up the feature space into a Voronoi diagram, where each region belongs to one centroid.

3. Strengths and Weaknesses

Strengths

  • Extremely Fast: Both training and prediction are incredibly fast since they only involve calculating means and distances.
  • Simple and Interpretable: The model is easy to understand, as each class is represented by a single, average point.
  • Robust to Noise: By averaging all points, the model is naturally robust to outliers.

Weaknesses

  • Assumes Spherical Classes: The model works best when classes are roughly spherical and equally sized. It performs poorly with complex, non-convex shapes.
  • Sensitive to Feature Scaling: Like k-NN, it relies on distances, so feature scaling is mandatory.

4. Conclusion

The Centroid Partition Classifier is a powerful baseline model due to its speed and simplicity. While it makes strong assumptions about the data's structure, it provides a fast and interpretable starting point for many classification problems.
