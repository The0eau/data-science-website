3. Step 2: Transformation

Financial data requires specific transformations to be useful for reporting. We apply the following rules:

  • Forex Normalization: Convert the Amount from USD to EUR (static rate: 0.92).
  • High-Value Tagging: Identify transactions over 100 EUR.
  • Audit Metadata: Add a processed_at timestamp.
# ETL - TRANSFORM
# 1. Currency Conversion
df['amount_eur'] = (df['Amount'] * 0.92).round(2)

# 2. Risk Tagging
df['is_high_value'] = df['amount_eur'] > 100

# 3. Clean columns (keep PCA features and new metrics)
cols_to_keep = ['Time', 'amount_eur', 'is_high_value', 'Class', 'V1', 'V2', 'V3']
df_transformed = df[cols_to_keep].copy()

# 4. Lineage
df_transformed['processed_at'] = datetime.now().strftime("%Y-%m-%d %H:%M:%S")

4. Step 3: Load

Finally, we load the cleaned financial records into our local SQLite Data Warehouse.

# ETL - LOAD
db_path = '../../data/processed/company_warehouse.db'
engine = create_engine(f'sqlite:///{db_path}')

# Load the data (Replaces the table if it already exists)
df_transformed.to_sql('fraud_audit_report', engine, if_exists='replace', index=False)

print(f"Pipeline executed successfully! Database location: {db_path}")
